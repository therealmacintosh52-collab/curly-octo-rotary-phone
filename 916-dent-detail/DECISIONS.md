# 916 Dent & Detail — project decisions & assumptions
| ID | Decision / assumption | Why |
|---|---|---|
| P-001 | Project lives in `916-dent-detail/` inside the org repo (branch `claude/916-dent-detail-build`). | Repo is the only persistent store; containers are ephemeral. |
| P-002 | Source video has an AAC audio stream and an embedded MJPEG cover stream; both stripped. 241 frames @24fps → ~120 frames means every 2nd frame. | Verified with ffprobe. |
| P-003 | No hero-video-wide.mp4 supplied → desktop uses the vertical scrub in a tall rounded panel (55% width) over blurred hero-beading.png. | Spec fallback. |
| P-004 | Everything external (Supabase, Stripe, Twilio, Resend, Anthropic, GA4, Meta) has a mock/no-key mode. | Hard gate: no accounts/spend by agents; app must run with zero keys. |
| P-005 | Next.js 16.4.1 (`npm view next version` on 2026-10-15), React 19.3.1, Turbopack build. TypeScript pinned `~5.9` and ESLint 9: TS 7.0.2 is "latest" but typescript-eslint 8 peers `typescript >=4.8.4 <6.1.0`. | Lint must run clean; TS 7 would break the lint toolchain. |
| P-006 | Tailwind v4, tokens in CSS-first `@theme` (`src/app/globals.css`), no `tailwind.config.js`. Builder agent rule "never add Tailwind" is for `blueprint/` client sites; this SPEC and D-029 require Tailwind. | v4 has no JS config by default; `@theme` generates `bg-onyx`, `text-gold` and the rest. |
| P-007 | Hero pin = CSS `position: sticky` stage inside a 350svh track (100svh stage + 250svh scrub), not a GSAP pin. ScrollTrigger only maps progress. An inline head script picks scrub vs static before first paint. | No pin-spacer insertion means no layout shift (CLS 0 measured). |
| P-008 | Static state (reduced motion / ≤2 cores / ≤2 GB / Save-Data) = LAST frame (fully beaded, clean) + all copy fading in. Reduced motion is served by `<picture media="(prefers-reduced-motion: reduce)">` (no JS); low-end swaps in via JS. Scrub mode starts on frame 0 (dent visible). | Showing the dented frame next to "Dents gone." contradicts the copy; the last frame is the result. |
| P-009 | 121 frames (every 2nd of 241, includes the last). Mobile 720x1280 q80; desktop = 720x1000 crop (top 140 px) of the same 720w source, q80, no upscaling. | No wide video exists. Upscaling adds bytes, not detail. The desktop panel is roughly square, so the crop drops pixels that are never shown. |
| P-010 | Loading: poster `<img>` immediately (fetchpriority high); first 10 frames 2.5 s after `load` or on first intent; GSAP/ScrollTrigger/Lenis and the other 111 frames on first scroll/touch/key/pointer, nearest-to-current first, then coarse-to-fine (every 8th, 4th, 2nd, rest), 4 at a time. | Lighthouse TBT dropped from 1,130 ms to 90-250 ms once motion JS was moved off the load path. |
| P-011 | Header logo = transparent D-mark (`d-mark-80.webp`) + "916 DENT & DETAIL" as live Michroma text. The full lockup stays for OG/footer use. | The full lockup at 40 px tall makes the wordmark about 6 px high, which is illegible. |
| P-012 | Eco section copy kept general ("low-water methods", "runoff captured", "the way Sacramento-area stormwater rules intend"); no equipment, permit or volume claims. `[OWNER: confirm reclaim equipment & permits]` in TODO.md. | SPEC asks for the section; specifics are unverified. |
| P-013 | Reviews = 3 dashed cards visibly marked `[OWNER] real review n` and "Placeholder, not a customer review". No stars, no counts, no aggregateRating in JSON-LD. | SPEC + hard rule: no invented reviews/ratings. |
| P-014 | Phone placeholder (916) 555-0100 (fictional 555-01xx range), email hello@example.com; visible `[OWNER]` markers in UI and both omitted from JSON-LD while `placeholder: true`. `npm run check:owner` exits 1 until every placeholder is gone. | tel:/sms: links need a value; a reserved fictional number cannot reach a stranger. |
| P-015 | Fonts: woff2 from @fontsource/michroma@5.3.0 + @fontsource/inter@5.3.0 (400, 600), subset to Basic Latin + Latin-1 + common punctuation by `scripts/subset-fonts.sh` (66 KB → 40 KB). `font-display: swap` kept. | Bytes before first paint drive simulated mobile LCP. |
| P-016 | Posters AVIF q36 (mobile 22 KB) instead of q50 (40 KB); visually compared, dent still crisp. Frames stay q80 per SPEC. | LCP budget. |
| P-017 | No runtime image optimizer (`images.unoptimized`): every image is pre-sized by the pipeline; plain `<img>`/`<picture>` with explicit width/height. | Predictable bytes; no sharp at runtime on the server. |
| P-018 | Membership tiers named Maintain / Protect / Showroom with proposed contents; featured tier labelled "Recommended" (not "Most popular"). | "Most popular" would be an unsupported claim. |
| P-019 | /book is a real "text us a photo" page (sms:/tel: CTAs) until the Phase 2 engine. No "coming soon" copy shown to customers. | SPEC: nav must not 404; shells must point at the right CTA. |
| P-020 | Section motion = one GSAP timeline per section keyed by `data-motion` (steps, grid, reveal, parallax, draw, pins, tiers, slide, fade). Nothing is hidden before JS; no motion in static mode. | Restrained, and content still works without JS. |
| P-021 | Service-area map is a schematic inline SVG (approximate relative positions, labelled "not to scale") plus a real `<ul>` of the 14 cities. | No external map script; the list is the accessible source. |
