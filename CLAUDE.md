# Repo guide

Quantum Growth OS lives in `quantum-growth-os/`. Read `quantum-growth-os/CLAUDE.md` and follow its
workflow rules before any work there.

Everything else in this repo (public sales page in `sites/quantum-growth/`, the client-site factory in
`sites/phils-auto-fleet-repair/`, `SITE-PROMPT.md`, the dropship folders) is unrelated to the OS and does
not need that file loaded.

`.claude/settings.json` sets `opusplan` (Opus plans, Sonnet executes) and Haiku subagents for this whole repo.
