# library — reusable assets (reuse > adapt > build new)

Check here before any research, build, or outreach. Each cycle extracts what worked into the right folder. Research older than 30 days is re-verified before reuse; anything older than 6 months is stale.

| Folder | What belongs here | Writer |
|---|---|---|
| `playbooks/` | Step-by-step processes that worked, written so the next run is faster and cheaper | Orchestrator (agents propose via handoff) |
| `research/` | Dated research caches with evidence tables (`<topic>-<YYYY-MM-DD>.md`) | scout |
| `templates/` | Site/listing/offer templates and intake forms | builder |
| `outreach/` | Outreach scripts, sequences, posting calendars, versioned by date | growth |
| `checklists/` | QA checklists per deliverable type | qa |
| `code/` | Reusable code modules and scripts | builder |
| `failure-patterns.md` | Ways plans die here, with the leading indicator and the fix | red-team |
