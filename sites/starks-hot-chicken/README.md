# Stark's Hot Chicken — site

Static site generated by `build.py` from `content.py`, on the shared engine in
`sites/_engine/`. Python 3 standard library only — no npm, no framework, no
dependencies.

```bash
python3 build.py                      # → public/
python3 build.py --relative           # relative links (file:// or subdir hosting)
python3 ../_engine/audit.py public    # must report 0 errors
```

**Edit `content.py`, never `public/`.** Pages, schema, sitemap, llms.txt and nav
all regenerate from it.

## Why this site exists in this shape

The reference design (`starks-hot-chicken.com`) is visually strong and almost
undiscoverable. Its menu, featured dishes, category nav and heat scale are empty
`<div>`s filled at runtime by `assets/js/menu-data.js`. No major AI crawler runs
JavaScript — GPTBot fetches JS in ~11.5% of requests and executes none;
ClaudeBot ~23.8%, none — so the menu, the single most-searched thing about a
restaurant, is invisible to ChatGPT, Claude and Perplexity.

This build keeps the cinematic feel and puts every word in the HTML.

| | Reference site | This build |
|---|---|---|
| Menu in HTML source | No — JS-rendered | Yes, all 26 items with prices |
| JSON-LD | None | Linked `@graph` on all 24 pages |
| `canonical` | Missing | Absolute, every page |
| `og:image` | Relative — unfurls break | Absolute |
| Favicon | `.jpg` | SVG + manifest |
| Indexable URLs | 1 (hash anchors) | 24 |
| hreflang | None | en / es / ko / x-default, every page |
| Third-party blocking resources | Google Fonts, GSAP, ScrollTrigger, Lenis, CF beacon | None |
| `llms.txt` | None | Generated from the page registry |

## Open questions for the owner

1. **Two domains.** `starks-hot-chicken.com` and `starkshotchicken.com` both
   resolve, and the first sends every pickup CTA to the second. That splits link
   equity and the entity. `content.py:BASE` currently assumes
   `starks-hot-chicken.com` wins. Needs a decision, then page-level 301s.
2. **The real menu.** `MENU` in `content.py` is **reconstructed** from the
   reference markup plus public listings. Replace it wholesale from
   `assets/js/menu-data.js`. Prices shown are delivery-platform prices.
3. **The 4.7 / 3,000+ rating claim.** Present on the reference site as
   unattributed decorative text. Not marked up here — first-party
   `aggregateRating` is self-serving review markup. Either attribute it
   per-platform or drop it.
4. **Coordinates.** `lat`/`lng` in `content.py` are approximate. Verify against
   Google Business Profile.
5. **Hours.** Read from the reference site's own markup, but third-party
   listings disagree slightly. Confirm.

## Assets

`assets/img/` currently holds **generated placeholders** — diagonal-hatched PNGs
so they can never be mistaken for real photography in a screenshot. Regenerate
with `python3 tools/make_placeholders.py`.

Replace with real files and update paths in `content.py` (`MENU[*].items[*].image`
and `GALLERY`). Needed: logo, storefront, entrance, interior, signature sando,
and one shot per menu item.

Fonts: the CSS asks for Anton + Manrope with solid fallbacks, but does **not**
link Google Fonts — that is a render-blocking third-party request. Drop
self-hosted `anton.woff2` / `manrope.woff2` into `assets/fonts/`, add
`@font-face` rules to `assets/css/site.css`, and a `<link rel="preload">` via
the renderer's `extra_head`.

## Structure

```
content.py    every business fact, the menu, heat levels, gallery
build.py      page bodies + the build driver
assets/       css, js, img — copied into public/ verbatim
tools/        make_placeholders.py
public/       generated output (committed)
```

24 indexable pages: home, menu index + 8 sections, heat levels, order,
koreatown, about, guides index + 3 guides, faq, catering, es, ko, contact,
privacy. Plus noindex 404.
