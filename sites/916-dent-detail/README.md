# 916 Dent & Detail: website

Static site (HTML, CSS, about 4 KB of vanilla JS per page type). Generated by `build.py` into `public/`. Nothing here is published; `public/` is deploy-ready once the placeholders are stamped and `tools/lint.py` passes.

## Preview locally

```
python3 build.py                 # writes public/ (needs Python 3 with Pillow; Node + Playwright only for new share images)
python3 tools/serve.py 8080      # clean URLs, 404 page, the real _headers (CSP) applied, gzip
# open http://localhost:8080/
```
Before stamping, canonicals and the sitemap contain `{{DOMAIN}}` and the form shows "This form isn't connected yet". That is intended.

## Placeholders and the one phone setting

| Token or flag | Where it lives | Stamped by |
|---|---|---|
| `{{DOMAIN}}` | canonicals, Open Graph, JSON-LD, sitemap, robots, llms.txt | `--domain example.org` (bare host) |
| `{{FORM_ENDPOINT}}`, `{{FORM_ORIGIN}}` | the two forms, CSP in `_headers` | `--form-endpoint https://...` or `/path` (also removes the "not connected" notice and enables Send) |
| `{{ANALYTICS_ID}}` | one `<meta name="analytics-id">`; no analytics script ships | `--analytics ID` or `--analytics none` |
| `PHONE_CONFIRMED` | `build/config.py` (`False`), which also holds the phone in one place | `--phone-confirmed`, or set the flag `True` and rebuild |

```
python3 tools/stamp.py --domain yourdomain.com --form-endpoint https://forms.example/yourform --analytics none --phone-confirmed
python3 tools/lint.py            # must print "lint ok"; it fails while any token, marker, banned claim or other business name remains
python3 tools/check.py           # structure: links, canonicals, one H1, titles, JSON-LD, sitemap parity (run on the unstamped build)
```
`--out DIR` stamps a copy and leaves `public/` untouched. Phone, Instagram, place list, descriptions and the review link are all in `build/config.py`; edit and rebuild.

## Deploy (Cloudflare Pages, or any static host)

1. Stamp, then lint (above). Upload the `public/` folder: Cloudflare Pages "Direct Upload", or connect the repo with build command `python3 sites/916-dent-detail/build.py && python3 sites/916-dent-detail/tools/stamp.py ...` and output directory `sites/916-dent-detail/public`.
2. `_headers` (security headers, strict CSP, immutable cache for `/assets/*`) and `_redirects` use Cloudflare Pages and Netlify syntax. On a host that ignores them, copy the same headers into its config.
3. Serve over HTTPS and redirect http to https and www to the bare domain (or the reverse) at the host.
4. If you add an analytics script later, add its origin to `script-src` and `connect-src` in `build.py` (HEADERS/csp) and mention it in `/privacy/`.
